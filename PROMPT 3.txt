--------------------------------------------------

--------------------------------------------------

Antes de criar a campanha, confira:

- Página do Facebook;

- conta de anúncios;

- pixel/dataset;
- eventos;

- checkout;

- criativos;
- textos;
- identidade da marca.

--------------------------------------------------

--------------------------------------------------
FASE 3 — CONJUNTO DE ANÚNCIOS
--------------------------------------------------

Use o público definido na Etapa 2.

Não amplie ou restrinja arbitrariamente o público apenas porque a Meta recomenda.

Analise:
- localização;
- idade;
- gênero;
- interesses, se necessários;
- expansão Advantage+;
- posicionamentos;
- evento de conversão.

Escolha o evento de conversão correto para o estágio atual do funil.

Se o pixel/evento de compra estiver corretamente configurado, priorize COMPRA.

Se não estiver configurado corretamente, NÃO finja que está.

--------------------------------------------------
FASE 4 — ANÚNCIOS
--------------------------------------------------

Configure inicialmente os melhores 3 criativos aprovados.

Cada anúncio deve ter:
- criativo;
- copy;
- headline;
- CTA;
- URL correta.

Não altere a promessa aprovada.

Faça uma revisão de política antes de salvar.

--------------------------------------------------
FASE 5 — RASTREAMENTO
--------------------------------------------------

Verifique se conseguimos medir:

- clique;
- visualização da página;
- início do checkout;
- compra.

Se possível, use parâmetros UTM consistentes.

Não invente eventos.

Antes de publicar, confira:

✓ público
✓ posicionamentos
✓ criativos
✓ copy
✓ URL
✓ checkout
✓ evento
✓ rastreamento

✓ políticas

Depois deixe tudo em RASCUNHO.

PARE.

Não publique.

--------------------------------------------------
FASE 7 — APÓS MINHA AUTORIZAÇÃO
--------------------------------------------------

Quando eu disser explicitamente:

“PODE PUBLICAR”

você poderá publicar a campanha.

Depois acompanhe os dados e não faça alterações impulsivas.

--------------------------------------------------
FASE 8 — OTIMIZAÇÃO
--------------------------------------------------

Não declare vencedor com base em poucas horas de dados.

Analise separadamente:

CTR
CPC
CPM
taxa de clique para página
início de checkout
custo por checkout
compras
CPA
ROAS

Diagnostique primeiro O QUE está quebrado:

CRIATIVO → clique baixo
PÁGINA → clique bom, conversão baixa
OFERTA → checkout bom, compra baixa
PÚBLICO → tráfego inadequado
RASTREAMENTO → dados inconsistentes

Não altere várias variáveis simultaneamente sem motivo.

--------------------------------------------------
FASE 9 — ESCALA
--------------------------------------------------

Quando houver dados suficientes e sinais consistentes de conversão:

1. identifique os criativos/ângulos com melhor desempenho;
2. produza novas variações desses ângulos;
3. mantenha uma versão de controle;
4. aumente orçamento gradualmente;
5. monitore CPA e ROAS;
6. não escale simplesmente porque houve uma venda isolada.

Escalar significa aumentar investimento preservando economia unitária aceitável, não simplesmente aumentar orçamento.
